
| perf Event | wasmtime → wasmer (cranelift) 一致性 | 备注 |
|---|---|---|
| `instructions-retired` / `cpu-cycles` | 与时间比 Spearman 同方向、同显著（wasmtime ρ≈0.80/0.93 → wasmer ρ≈0.81/0.94）。两 runtime 都把时间端的主要解释力压在「周期/指令体量」两块上。 | wasmer 的 wasm/native 中位指令膨胀略高（≈1.07×），与 wasmer R² 更大相符。|
| `L1-icache-load-misses` | 仍在两 runtime 的 FDR q<0.05 显著名单（wasmtime ρ≈0.76，wasmer ρ≈0.67）。wasmer 自身相对 wasmtime 平均 I-cache miss ≈ **1.72×**（wasm-jit）/ 1.79×（wasm-aot）。 | wasmer 的取指压力明显更大，但与时间比的相对关系保持同向。|
| `branches-retired` | 两 runtime 同为正向显著（wasmtime ρ≈0.66 → wasmer ρ≈0.46）。 | wasmer 上系数减弱，原因是 `conditional_branches` 从 wasmtime 上的不显著变为 wasmer 的 FDR 显著（ρ≈0.47），二者在两个 runtime 上有侧重切换。|
| `conditional-branches` | **wasmer 新增 FDR 显著** (ρ≈0.47 vs wasmtime 0.20，FDR q<0.05 仅在 wasmer 端通过)。 | wasmer 后端对条件分支的处理路径不同（cranelift 分支选择/检查与 wasmtime 实现差异）。|
| `branch-misses` | wasmtime 不显著 (ρ≈0.30) → wasmer FDR 显著 (ρ≈0.31, q<0.05)。 | wasmer 上预测器压力略高于 wasmtime。|
| `all-loads-retired` / `all-stores-retired` | 两 runtime 都**未通过 FDR**；在桥接链腰里仍是「静态结构 → 访存退役比」最稳定的连接边。 | 这与 4.29后/5.11 的结论一致：访存退役比是「链腰」角色而非「链尾」。|

> 静态 IR → perf → 内部时间比 的三段证据链在 wasmer 上仍然成立：
> 静态-时间 ρ 序列跨 runtime 相关 ≈ **0.972**，桥接 184 配对 ρ 相关 ≈ **0.956**，Lasso 非零特征 9/10 交集内符号一致。
